# StreamingInteractiveProofs
## Protocols
1. Equality
2. 0th Frequency Moment
3. 1st Frequency Moment
4. Bivariate 2nd Frequency Moment
5. Multivariate 2nd Frequency Moment
6. Bivariate Index
7. Multivariate Index
8. Polynomial Evaluation Problem
9. Honest Verifier Zero Knowledge Index
10. Strong Zero Knowledge Index

## Setup
1. clone the repository
2. import numpy, galois, secrets, pytest matplotlib and Juypter libraries

## To run a protocol:
1. if synthesising data, run the stream generator
2. run the protocol

## To run tests:
1. cd tests
2. run unittest filename.TestClass

## To get graphs
1. go to evaluation folder and run files
